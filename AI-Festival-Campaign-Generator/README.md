# 🎁 AI Festival Campaign Generator

A production-style Multi-Agent AI Marketing Automation System built using **n8n**, **Google Gemini**, **Google Drive**, **Google Sheets**, and **Gmail**.

This workflow automatically creates complete festival marketing campaigns for any product or brand. It researches the festival, generates marketing copy, creates AI-powered visuals, performs quality assurance, stores campaign assets, and emails professionally formatted campaign kits.

# ⚙ Installation

1. Clone the repository.

```bash
git clone https://github.com/yourusername/AI-Festival-Campaign-Generator.git
```

2. Open n8n.

3. Import

```
workflow/festival-campaign-generator.json
```

4. Configure

- Gemini API

- Gmail

- Google Drive

- Google Sheets

5. Execute the workflow.
